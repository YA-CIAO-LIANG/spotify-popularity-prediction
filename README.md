IS 507 Midterm Project (Team 13). This project studies how well a song's Spotify popularity can be predicted from its audio features (danceability, energy, valence, …) and its lyrics (length, repetition, sentiment, TF-IDF).

## Dataset

[550K Spotify Songs: Audio, Lyrics and Genres](https://www.kaggle.com/datasets/serkantysz/550k-spotify-songs-audio-lyrics-and-genres) on Kaggle. Notebook 1 downloads it automatically with `kagglehub`.

> **Note:** The `data/` folder is not included in this repository because the files are too large for GitHub. Run **Notebook 1 first** to download the raw data and generate `songs_clean.csv`, `songs_clean_audio.csv` and the other cleaned datasets that Notebooks 2 and 3 need.

## Notebooks

1. **Data Cleaning and Splitting** — year filter (2009–2025), invalid-value removal, lyrics cleaning and English-language filter, deduplication, train / validation / test split, and the baseline. Exports the clean lyrics and audio datasets.
2. **Lyrics Features** — ten handcrafted lyrics features (length, repetition, VADER sentiment), TF-IDF representation, association with popularity, and model comparison on the test set.
3. **Audio Features** — descriptive statistics of the nine audio features and their correlation with popularity.

Run the notebooks in order: Notebooks 2 and 3 read the datasets exported by Notebook 1.

## How to Run

**Google Colab (recommended):** click a badge above. The notebooks mount Google Drive and save data, figures and results under the project folder there.

**Locally:**

```bash
pip install -r requirements.txt
jupyter notebook
```

The `drive.mount(...)` cells are Colab-only; when running locally, skip them and set `PROJECT_DIR` to a local path.
